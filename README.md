# 판타지 지도 생성기

시드 하나로 지형·강·기후·국가·도시·도로·지명까지 갖춘 판타지 지도를 만드는 브라우저 앱입니다. 같은 시드와 옵션이면 항상 같은 지도가 나오므로, 링크 하나로 지도를 공유하거나 TRPG·시뮬레이션의 무대로 다시 불러 쓸 수 있습니다.

- 색을 입힌 지형도 (고도 음영, 생태 지역, 해안선)
- 지명 스타일: **한국어풍**(기본) / 서구 판타지풍
- 대륙형·군도형, 육지 비율·국가 수·도시 수·기후 조절
- 레이어 켜고 끄기, 마우스 오버 셀 정보
- PNG·JSON 내보내기, 현재 옵션이 담긴 공유 링크
- **지형 편집**: 브러시로 땅을 올리고·내리고·고르고·다듬으면 강·기후·생태·국가·도시가 다시 계산됨
- **도시·국경 편집**: 도시 이동·추가·삭제·이름 바꾸기·수도 지정, 국경 칠하기, 국가 만들기·없애기·이름 바꾸기
- **시설 편집**: 도로·철도·해상 항로 그리기(지형을 따라 자동 경로), 항구, 시설물 9종(성·요새·기지·공항·사원·광산·탑·유적·등대), 옮기기·지우기, 다리·터널(자동 표기 + 직접 놓기)

## 실행

Node.js 22.18 이상이 필요합니다 (테스트가 Node의 TypeScript 타입 제거 실행을 씁니다).

```bash
npm ci
npm run dev        # 개발 서버
npm test           # 테스트 (node:test)
npm run build      # dist/ 정적 빌드
npm run test:e2e   # 브라우저 E2E (Playwright, 빌드 후 실행)
```

E2E는 빌드된 `dist/`를 `vite preview`로 띄워 실제 브라우저에서 검사합니다.

- 기능: 지도 생성·JSON 왕복, 지형/도시/국경 편집과 되돌리기, 도로·철도·항로·항구·시설물·다리·터널(용도 규칙 포함), 확대 중 배치 정확도·핀치 취소, 화면 폭별 확대 버튼 위치, 휴대폰 터치.
- 브라우저: Chromium 일반·고해상도(배율 2), WebKit(Safari 엔진). 처음 한 번은 `npx playwright install chromium webkit`으로 브라우저를 받아야 합니다.
- 시각 회귀(`e2e/visual.spec.ts`): 고정 시드 지도의 캔버스 픽셀을 `e2e/__screenshots__/`의 기준 이미지와 비교합니다. 글꼴 차이를 피하려고 지명 레이어는 끄고 비교하며, Linux Chromium에서만 돕니다. 렌더링을 의도적으로 바꿨다면 `npx playwright test e2e/visual.spec.ts --update-snapshots`로 기준 이미지를 다시 만들어 함께 커밋합니다.

## 확대·이동

- 마우스 휠로 커서 위치를 기준으로 확대·축소합니다 (100%~800%). 지도 오른쪽 위 `+`·`−`·`⤢` 버튼(폭 600px 이하 화면에서는 지도 아래)이나 키보드 `+`·`-`·`0`으로도 됩니다.
- 편집 모드가 꺼져 있으면 왼쪽 버튼으로 끌어서 옮깁니다. 편집 중에는 `스페이스바`를 누른 채 끌거나 가운데·오른쪽 버튼으로 끕니다.
- 터치 화면에서는 두 손가락으로 확대·이동합니다. 한 손가락으로 편집하던 중에 두 번째 손가락이 닿으면 그 편집은 취소됩니다.
- 움직이는 동안에는 미리 그려 둔 바탕을 늘려 보여 주되 지명은 매 프레임 새로 얹어 크기가 흔들리지 않고, 멈추면 그 배율로 선명하게 다시 그립니다.
- 지도는 화면의 실제 해상도(devicePixelRatio, 최대 3배·폭 4096px)로 그려서 고해상도 화면에서도 선명합니다. 지형을 칠하는 동안에만 바탕을 낮은 해상도로 그려 속도를 지키고, 손을 떼면 다시 선명하게 그립니다.
- 지명 글자는 확대해도 화면에서 같은 크기로 그립니다. 확대할수록 글자끼리 덜 겹쳐서 가려졌던 지명이 더 드러납니다. 지형·선·아이콘은 지도와 함께 커집니다.
- 휴대폰처럼 지도를 작게 줄여 보여 주는 좁은 화면에서는 지명과 도시·시설 표시를 키웁니다 (원래 크기의 85% 아래로 작아지지 않게, 최대 3배). 대신 처음에는 겹치지 않는 주요 지명만 보이고, 확대할수록 더 드러납니다. 키운 표시는 확대할수록 원래 크기로 돌아갑니다. PNG 저장에는 적용하지 않습니다.
- 확대해서 보고 있어도 `PNG 저장`은 항상 지도 전체를 원래 크기로 저장합니다.

## 편집

`편집 모드`(단축키 `E`)를 켜고 `지형`·`도시`·`국경`·`시설`·`자원` 탭 중 하나를 고릅니다.

### 지형

| 도구 | 동작 |
|---|---|
| 융기 | 땅을 높입니다. 바다에 칠하면 섬이 생깁니다. |
| 침강 | 땅을 낮춥니다. 계속 칠하면 바다가 됩니다. |
| 평탄화 | 처음 누른 지점의 높이에 맞춰 고릅니다. |
| 부드럽게 | 주변과 섞어 거친 지형을 다듬습니다. |

- 칠하는 동안에는 지형·강·생태만 실시간으로 갱신하고, 손을 떼면 도시·국가·도로를 다시 배치합니다.
- **이름 유지**: 다시 배치해도 같은 자리(또는 도시 간격보다 가까운 곳)에 있는 도시·봉우리, 이전 수도를 품은 국가(색 포함), 많이 겹치는 강은 이전 이름을 물려받습니다. 새로 생긴 곳만 새 이름을 받습니다. 지금까지 나온 이름을 위치와 함께 기억해 두므로, 되돌리기로 돌아온 도시도 원래 이름을 찾습니다.

### 도시·국경

| 도구 | 동작 |
|---|---|
| 이동 | 도시를 끌어 옮깁니다. 수도를 옮기면 그 자리가 그 나라 땅이 됩니다. |
| 추가 | 빈 땅을 누르면 도시가 생기고 이름이 자동으로 붙습니다. |
| 삭제 | 일반 도시를 지웁니다 (수도는 지울 수 없음). |
| 이름 바꾸기 | 도시 이름을 바꿉니다. 국가 이름은 국경 탭의 '선택한 국가 이름 바꾸기'로 바꿉니다. |
| 수도 지정 | 도시를 그 도시가 속한 나라의 수도로 만듭니다. |
| 새 국가 | 도시를 수도로 하는 새 나라를 세웁니다. 원래 나라 땅이면 두 수도 중 가까운 쪽으로 영토를 나누고, 무소속 땅이면 주변 무소속 땅을 가져갑니다 (최대 30개국). |
| 국경 칠하기 | 고른 나라(또는 무소속)의 영토로 칠합니다. 다른 나라 수도 자리는 칠해지지 않습니다. |
| 국가 없애기 | 국경 탭에서 고른 나라를 없앱니다. 영토는 무소속 또는 지정한 나라로 넘어가고, 수도였던 도시는 일반 도시로 남습니다. |

- 도시·국경을 처음 편집하는 순간 자동 배치를 멈추고 그때의 문명을 고정합니다. 이후 지형을 편집해도 도시·국경은 움직이지 않고 도로만 다시 계산되며, 물에 잠긴 도시는 숨겨졌다가 땅이 다시 생기면 돌아옵니다. 새로 생긴 땅은 무소속입니다.
- `자동 배치로`를 누르면 직접 편집한 문명을 버리고 자동 배치로 돌아갑니다. 국가 수·도시 수 옵션은 자동 배치일 때만 적용됩니다.
- 지명 스타일을 바꾸면 직접 편집한 도시·국가에도 그 스타일 이름이 붙고, 원래 스타일로 돌아오면 원래 이름(직접 바꾼 이름 포함)이 다시 나옵니다.

### 시설

| 도구 | 동작 |
|---|---|
| 도로 | 출발점에서 도착점까지 끌어 놓으면 지형 비용을 따라 도로가 생깁니다. 도시 근처에서 시작·끝내면 도시에 붙고, 직접 놓은 다리·터널도 길로 씁니다 (다리로 이은 섬까지 도로가 이어짐). |
| 철도 | 도로와 같지만 경사에 훨씬 민감해 급경사를 피해 돌아가고, 우회가 너무 길면 고산 구간을 터널로 관통합니다. 검은 선 위 흰 점선으로 그립니다. |
| 항로 | 항구에서 다른 항구까지 끌어 놓으면 바다를 따라 항로가 생깁니다. 얕은 연안보다 깊은 바다를 조금 더 선호합니다. 남색 점선으로 그립니다. |
| 다리 | 육지에서 물(강·호수·해협) 건너편 육지까지 끌어 놓으면 곧은 다리를 놓습니다 (250px까지, 길이에 따라 교각 표시). **도로용**(밝은 상판)과 **철도용**(어두운 상판·침목)을 골라 놓습니다. |
| 터널 | 두 육지 지점 사이에 곧은 터널을 놓습니다. 산 관통·해저 터널 모두 됩니다 (250px까지). 도로용(갈색 점선)·철도용(짙은 회색 점선)을 고릅니다. |
| 항구 | 바다에 닿은 해안 육지에만 둘 수 있습니다. |
| 시설물 | 성·요새·기지·공항(평지 전용)·사원·광산·탑·유적·등대(해안 전용) 중 하나를 둡니다. |
| 이동 | 항구·시설물·다리·터널을 끌어 옮깁니다 (놓을 때와 같은 조건). 다리·터널은 끝점을 끌면 그 끝만, 가운데를 끌면 통째로 옮겨집니다. 항구를 옮기면 이어진 항로를 새 자리로 다시 계산하고, 이어지지 않으면 그 항로를 지웁니다. |
| 용도 전환 | 다리·터널을 누르면 도로용 ↔ 철도용이 바뀝니다. 그 위를 지나던 원래 용도의 길은 다른 길로 다시 이어 보고, 길이 없으면 끊겨 그려집니다. |
| 지우기 | 누른 곳에서 가장 가까운 시설을 지웁니다. 순서: 항구·시설물 → 직접 놓은 다리·터널 → 자동 다리·터널 표기(숨김) → 도로·철도·항로. |

- 항구·시설물은 `이름` 칸에 적어 두면 놓을 때 이름이 붙습니다 (비워 두면 이름 없음).
- 도로를 처음 그리거나 지우면 자동 도로를 그 상태로 고정합니다. `도로 자동 배치로`로 해제할 수 있습니다 (철도·항구·시설물은 그대로).
- 직접 놓은 다리·터널은 **같은 용도의 길**이 됩니다: 도로는 도로용, 철도는 철도용만 건넙니다. 자동 도로도 도로용 다리를 건너므로, 다리로 이은 섬의 도시들은 자동으로 도로가 이어집니다. 터널을 지나는 구간은 길 선 대신 터널 표기로만 보입니다.
- 다리·터널을 **옮기면 그 위를 지나던 같은 용도의 도로·철도가 따라갑니다** (원래 출발점·도착점은 그대로 두고 새 자리 기준으로 다시 계산). 새 자리로 이어질 수 없는 경로와, 다리·터널을 지운 경우에는 끊긴 곳에서 나뉘어 그려집니다 (물 위에 선이 남지 않게).
- 용도 정보가 없던 예전 저장본의 다리·터널은 도로용으로 읽습니다. `용도 전환`으로 철도용으로 바꿀 수 있습니다.
- 지형을 편집해 물에 잠긴 시설은 숨기고, 도로·철도는 잠긴 구간에서 끊어 그립니다. 땅이 돌아오면 다시 보입니다.
- **다리·터널은 자동으로도 표기**합니다. 도로·철도(자동 도로 포함)가 강을 짧게 건너는 지점에는 다리를, 철도가 높은 산지(상대 고도 0.55 초과)를 2칸 이상 지나는 구간에는 터널(회색 점선과 양 끝 입구)을 그립니다. 원하지 않는 자동 표기는 지우기로 숨길 수 있습니다 (도로·철도는 그대로).
- 레이어에서 `철도`, `항로`, `항구·시설`을 따로 켜고 끌 수 있습니다.

### 자원

지도에는 천연자원이 시드에 따라 자동으로 놓입니다. 아이콘 테두리 색으로 분류를 구분하고, 지도 아래 범례에 종류별 개수가 나옵니다. 칸 위에 마우스를 올리면 셀 정보에 자원 이름·분류·매장량이 나옵니다.

| 분류 | 종류 | 주로 놓이는 곳 |
|---|---|---|
| 전략 자원 (적갈색, 매장량 있음) | 철광, 석탄, 석유, 말 | 철광: 구릉·산지 / 석탄: 숲·초원의 구릉 / 석유: 사막·습지·툰드라와 먼바다 쪽 얕은 바다 / 말: 초원·사바나 |
| 사치 자원 (보라) | 금, 은, 보석, 향신료, 비단, 진주, 모피 | 금: 구릉·사막(강가에 더 많음) / 은: 툰드라·침엽수림·구릉 / 보석: 열대우림·고산 / 향신료: 열대우림·사바나 / 비단: 온대림 / 진주: 따뜻한 연안 / 모피: 툰드라·침엽수림 |
| 기본 자원 (초록) | 목재, 곡물, 가축, 어장, 석재 | 목재: 숲 / 곡물: 초원(강가에 더 많음) / 가축: 초원·사바나 / 어장: 연안·호수 / 석재: 구릉·사막·고산 |

- 기본 지도(약 9,000셀)에 200개 안팎이 놓입니다. 셀 수(정밀도)를 바꿔도 지도 전체 개수는 비슷하게 유지됩니다.
- 전략 자원에는 매장량(자동 배치 2~8, 직접 놓을 때 1~20)이 있습니다.
- 배치는 셀 번호로 정해지는 난수와 주변 칸만 보고 결정하므로, 지형 일부를 편집해도 먼 곳의 자원은 대부분 그대로입니다. 지형을 칠하는 동안에도 자원이 함께 바뀌어 보입니다.
- 자원은 도시 배치에 영향을 주지 않습니다 (기존 시드의 도시·국경·지명이 그대로 유지되도록).
- `자원` 탭의 `놓기`로 고른 자원을 칸에 놓고(이미 있으면 바꿈), `지우기`로 가까운 자원을 지웁니다. 어장·진주는 바다·호수에만, 석유는 육지·바다 어디든, 나머지는 육지에만 둘 수 있습니다. `자원 자동 배치로`를 누르면 직접 편집한 자원을 버립니다.
- 직접 놓은 자원은 지형을 바꿔 자리가 맞지 않게 되면(예: 육지 자원이 물에 잠김) 숨겼다가 땅이 돌아오면 다시 보입니다.
- 레이어에서 `자원`을 끄면 아이콘과 범례가 함께 사라집니다. 같은 칸에 도시·시설이 있으면 자원 아이콘은 오른쪽 아래로 비켜 그립니다.

### 공통

- 되돌리기 `Ctrl+Z`, 다시 하기 `Ctrl+Shift+Z` (지형·도시·국경·시설·자원 편집을 합쳐 최근 50단계)
- 국가 수·도시 수·기후·지명 스타일은 편집한 지형을 유지한 채 바꿀 수 있습니다. 시드·육지 비율·지형 형태·정밀도를 바꾸면 편집 내용이 사라지므로 확인 창이 뜹니다.
- 편집 내용은 이 브라우저에 자동 저장되어 새로고침해도 남습니다. 공유 링크에는 담기지 않으므로, 다른 사람에게 보내거나 보관하려면 `JSON 저장` → `JSON 불러오기`를 쓰세요.

## 생성 과정

지도는 정사각 격자 대신 불규칙 다각형 셀(기본 약 9,000개) 위에서 만들어집니다. 해안선과 국경이 자연스럽고, 강·국경·도로가 셀 그래프 문제로 단순해집니다.

| 단계 | 방법 | 코드 |
|---|---|---|
| 셀 분할 | Poisson disk 샘플링 → 보로노이 다각형 | `src/mesh.ts` |
| 지형 | 도메인 워핑한 fBm 심플렉스 노이즈 + 능선 노이즈(산맥) + 대륙/군도 감쇠, 해수면은 육지 비율 분위수 | `src/terrain.ts` |
| 강·호수 | Priority-flood로 웅덩이를 메우고 내리막 방향으로 유량 누적, 깊게 메워진 곳은 호수 | `src/hydrology.ts` |
| 기후·생태 | 기온 = 위도 − 고도 감률, 습도 = 바다 거리 + 편서풍 비그늘 + 강·호수 주변 보정, 휘태커식 분류 | `src/climate.ts` |
| 도시 | 생태 거주성 × 해안·강·호수 보너스로 점수, 간격을 두고 수도·도시 배치 | `src/civ.ts` |
| 국가 | 수도에서 동시에 Dijkstra 확장 (산·강·습지 비용이 커서 국경이 지형을 따름) | `src/civ.ts` |
| 도로 | 도시 들로네 간선의 최소 신장 트리 + 일부 순환로, 지형 비용 A* (기존 도로 할인) | `src/civ.ts` |
| 천연자원 | 종류별 적합도(생태·고도·강·연안·수온) × 밀도로 셀 번호 난수 후보를 뽑고, 같은 종류는 간격 안의 최고 우선순위만, 다른 종류끼리 겹치면 전략 > 사치 > 기본 순으로 남김 | `src/resources.ts` |
| 지명 | 한국어풍: 음절 조합 + 지형별 접미사(포·진·천·산 등) + 순우리말, 실제 주요 지명 제외 / 서구풍: 2차 문자 마르코프 체인 | `src/names.ts` |
| 지형 편집 | 코사인 감쇠 브러시, 편집 단위 스냅샷 되돌리기, 무손실 로컬 저장 | `src/editor.ts` |
| 문명 편집 | 자동 배치를 고정한 편집 가능한 문명(도시·국가·셀별 소속), 입력 검증 | `src/civedit.ts` |
| 시설 | 도로(지형 비용)·철도(경사 제곱 비용, 고산은 터널 비용)·항로(수심 가중) A* 경로, 다리·터널 감지와 연결 그래프(경로가 다리·터널을 건넘), 항구·시설물·다리·터널 이동, 입력 검증 | `src/infra.ts` |
| 렌더링 | Canvas 2D, 음영·색을 이웃과 섞어 모자이크 완화, 겹침 회피 라벨 | `src/render.ts` |
| 화면·입력 | 기기 해상도 캔버스, 확대·이동(휠·버튼·키보드·끌기·두 손가락), 편집 입력은 main.ts로 넘김 | `src/ui/viewport.ts` |
| 칠하기 미리보기 | 칠하는 동안의 재계산(기후·강·생태 + 그리기 캐시)을 Web Worker에서 실행, 계산 중 들어온 요청은 최신 하나로 합침. 손을 떼면 메인에서 최종 계산. Worker를 못 쓰면 메인에서 계산 | `src/preview.ts`, `src/preview.worker.ts`, `src/ui/preview-client.ts` |
| 자연 재사용 | 고도 값의 해시가 같으면 기후·수계·생태·강을 다시 계산하지 않음 (도시·국경·시설 편집, 칠하기를 마친 뒤) | `src/world.ts` (`natureKey`) |

단계마다 독립된 난수열(`시드::단계명`)을 써서, 예를 들어 지명 스타일만 바꾸면 지형·국경·도시 위치는 그대로 두고 이름만 바뀝니다.

## JSON 형식

`JSON 저장`은 `fantasy-map/v1` 형식으로 셀(좌표·고도·기온·습도·생태·소속 국가·강 여부), 국가, 도시, 이름 붙은 강, 도로(셀 경로), 산봉우리를 내보냅니다. 고도·기온·습도는 0~1 상대값이며, 화면의 m·°C 표시는 이를 그럴듯하게 환산한 값입니다. 도시·국경을 직접 편집한 지도는 `civ` 항목(도시·국가의 지명 스타일별 이름, 수도, 색, 셀별 소속)이 추가로 들어가며, 불러오면 편집한 상태 그대로 열립니다. 철도·항로·다리·터널·항구·시설물은 `rails`·`seaRoutes`·`bridges`·`tunnels`·`ports`·`facilities`로, 편집 원본(고정한 도로 포함)은 `infra` 항목으로 저장됩니다.

천연자원은 `resources`에 최종 목록(자동 배치 + 직접 편집)으로 들어갑니다. 항목마다 `cell`, `kind`(영문 식별자: `iron`·`coal`·`oil`·`horses`·`gold`·`silver`·`gems`·`spices`·`silk`·`pearls`·`furs`·`wood`·`grain`·`cattle`·`fish`·`stone`), `name`(한국어 이름), `category`(`strategic`·`luxury`·`bonus`), 전략 자원이면 `amount`(매장량), 좌표 `x`·`y`가 있습니다. 직접 놓거나 지운 자원은 `resourceEdits`(`added`·`removed`)로 따로 저장되어 다시 불러오면 편집 상태로 열립니다. 예전 형식 파일도 그대로 읽히며, 이때 자원은 자동 배치를 씁니다.

## 배포

`main`에 푸시하면 GitHub Actions가 타입 검사·테스트·빌드·E2E 후 GitHub Pages에 배포합니다. 처음 한 번은 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 합니다. E2E가 실패하면 배포하지 않고, 실패 화면·trace를 `playwright-report` 아티팩트로 올립니다.
